# Resources Archive

This folder keeps supporting materials that back the MkDocs book but are not part of the rendered site.

- `docs/` contains legacy module guides, onboarding notes, and templates learners can download or edit.
- `environment/` stores the shared conda environment files and verification script.
- `notebooks/` houses the Python notebooks (with an `archive/` subfolder for older experiments).
- `data/` provides the raw/processed folder scaffold for staging datasets locally.
- `assets/` (in the repository root) stores images, slides, and icons. Use subfolders like `assets/images/week03/` and name files `week03_boundary_join_demo.png` to keep visuals organised.

Feel free to clean or reorganise these resources as you refine the course; the MkDocs site pulls content from `site_docs/`.
