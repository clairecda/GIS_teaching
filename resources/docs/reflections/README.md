# Reflection Templates

Place weekly reflection prompts or learner templates here. Each week has a seeded Markdown guide you can duplicate or adapt:

- `week01.md` — Installation notes and QGIS comfort checklist.
- `week02.md` — Design takeaways from symbology and layout practice.
- `week03.md` to `week06.md` — QGIS vector/raster, crime, and accessibility insights.
- `week07.md` — Bridge-to-Python readiness check.
- `week08.md` to `week10.md` — Python automation reflections (vector, raster, networks).
- `week11.md` — Design studio critiques and accessibility planning.
- `week12.md` — Capstone showcase debrief.

Encourage learners to copy the relevant template, add the date, and contribute their own notes throughout the course.
