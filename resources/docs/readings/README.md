# Course Readings

- `week01-what-is-gis.md` — Introductory reading for Week 1 pre-work (links to Esri overview + 5-minute video).
- `week02-data-models.md` — Vector vs. raster primer for Week 2.
- `week03-admin-boundaries.md` — Overview of administrative/statistical areas and why they matter.
- `week02-map-design-basics.md` — Colour theory, typography, and accessibility notes for Week 2–11.

Add additional readings as Markdown files or link to external resources with annotations.
