# Layout Template Guide

Use this outline when preparing the Week 2 layout workshop and Week 11 design studio. It describes a standard A3/A4 layout with hierarchy in mind. Convert to a visual diagram once finalised.

## Page Setup

- **Size:** A3 landscape (420 × 297 mm) or A4 landscape for lighter prints.
- **Margins:** 15 mm outer margins; 20 mm bottom margin to accommodate credits.
- **Grid:** Optional 12-column grid (with 5 mm gutters) to align elements.

## Core Sections

1. **Title Block (Top Left / Top Center)**
   - Map title (≤ 10 words), subtitle providing context.
   - Include issue/date or study area.
2. **Main Map Frame**
   - Occupies ~60% of page.
   - Use inset map for regional context (top right).
3. **Legend & Symbology**
   - Place immediately adjacent to main map or bottom right.
   - Use horizontal legend for continuous scales; vertical for categorical.
4. **Data Notes & Methodology**
   - Include short paragraph summarising data sources (with years) and processing.
   - Add CRS information (e.g., `EPSG:3857`) in small type.
5. **Charts / Infographics (Optional)**
   - Bar chart or callout to highlight key metric.
   - Align with grid columns to maintain balance.
6. **Credits & Accessibility**
   - Author name, course, and data credits along bottom margin.
   - Provide link/QR to accessible text description if available.

## Typography & Colour

- **Title:** 24–32 pt, bold sans-serif (e.g., Source Sans Pro).
- **Body text:** 10–12 pt, readable font (e.g., Public Sans).
- Use ColourBrewer palettes or course-approved palette for accessibility (check contrast ≥ 4.5:1).
- Limit to 3–4 core colours plus neutrals.

## Export Checklist

- [ ] Layers labelled clearly and consistently in legend.
- [ ] North arrow added only when map orientation is not obvious.
- [ ] Scale bar matches the projection (dynamic or static).
- [ ] Credits include data year, license, and source URL.
- [ ] Exported as PNG (for slides) and PDF (for print/archive).
- [ ] Metadata captured in reflection notes or README.

## Instructor Notes

- Provide a sample QGIS layout file (`.qpt`) using this structure.
- Encourage learners to annotate the template with sticky notes before customising.
- Use the same template to critique maps during Week 11 to reinforce design consistency.
