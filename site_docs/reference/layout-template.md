# Layout Template Guide

Use this structure during Week 2’s layout workshop and Week 11’s design studio to assemble clear, accessible map layouts.

## Page setup

- **Size:** A3 landscape (420 × 297 mm) or A4 landscape for lighter prints.
- **Margins:** 15 mm outer margins; 20 mm bottom margin for credits.
- **Grid:** Optional 12-column grid (5 mm gutters) to align elements.

## Core sections

1. **Title block** (top left or centred): concise title (≤ 10 words), short subtitle, date/issue.
2. **Main map frame:** occupies ~60% of the page; include inset map (top right) for regional context.
3. **Legend & symbology:** place near the main map (bottom right or side column). Use horizontal legends for continuous scales, vertical for categorical.
4. **Data notes & methodology:** brief paragraph summarising data sources (with years) and CRS (e.g., `EPSG:7856`). Add contact info or data URL if relevant.
5. **Charts / callouts (optional):** include small bar chart or statistic to highlight key takeaway.
6. **Credits & accessibility notes:** along the footer (bottom margin) list author, data licensing, and link/QR to accessible text description.

## Typography & colour

- Title: 24–32 pt bold sans-serif (e.g., Source Sans Pro).
- Body text: 10–12 pt readable font (e.g., Public Sans).
- Use ColourBrewer palettes or course-approved colour schemes; maintain contrast ratio ≥ 4.5:1.
- Limit to three or four core colours plus neutrals; reserve bright accents for focal information.

## Export checklist

- [ ] Legend labels and units are clear and consistent.
- [ ] North arrow only included if orientation isn't obvious.
- [ ] Scale bar matches the projection (dynamic or fixed).
- [ ] Credits list data year, license, and source URL.
- [ ] Exported as PNG (for digital viewing) and PDF (for print/archive).
- [ ] Metadata and reflections updated (Week 2 or Week 11 prompts).

## Tips for success

- Sketch your layout on paper before building it digitally to work out the visual hierarchy.
- During critiques, be ready to explain why you positioned each element where you did.
- Save your layout as a template file (`.qpt`) once finalized so you can reuse the structure for future maps.
