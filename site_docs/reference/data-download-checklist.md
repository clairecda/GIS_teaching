# Data Download Checklist

Tick off each item as you download files. Save everything to the correct week folder. See [Download Datasets](../onboarding/03-download-data.md) for detailed instructions.

---

## Folder structure reminder

Each week has its own folder:

```
intro-gis/
├── week01/
│   └── data/
│       ├── raw/        ← Downloads go here
│       └── processed/  ← Your modified files
├── week02/
└── ...
```
