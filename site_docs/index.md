# Introduction to GIS

Welcome to a 12-week, project-based journey through Geographic Information Systems. This course begins with hands-on QGIS skills and gradually transitions into Python-based analysis, helping you move from point-and-click workflows to reproducible code.

---

## Course structure

| Weeks | Focus | Tools |
|-------|-------|-------|
| 1-6 | GIS foundations | QGIS |
| 7 | Bridge to Python | Anaconda, Jupyter |
| 8-10 | Python automation | GeoPandas, Rasterio, OSMnx |
| 11-12 | Design & capstone | QGIS + Python |

**Capstone project:** You'll work on a spatial project throughout all 12 weeks, not just at the end. Start thinking about your topic in Week 1.

## Who this course is for

- Beginners curious about spatial analysis
- Researchers who want to visualise geographic data
- Anyone with a laptop (Mac, Windows, or Linux)

**No prior GIS or programming experience required.**

---

## Learning outcomes

By the end of the course you will be able to:

1. Use QGIS confidently for mapping and spatial analysis
2. Understand coordinate systems, projections, and data formats
3. Join data to boundaries and create thematic maps
4. Perform hotspot analysis, accessibility modelling, and terrain analysis
5. Automate workflows with Python and GeoPandas
6. Design accessible, publication-ready maps
7. Complete a portfolio-ready capstone project
