# Introduction to GIS

Welcome to a 12-week, project-based journey through Geographic Information Systems (GIS). This course begins with hands-on QGIS skills and gradually transitions into Python-based analysis, helping you move from point-and-click workflows to reproducible notebooks. Along the way you will explore crime, public health, environmental, and transport datasets while learning to communicate spatial stories with solid design principles.

## How the course is organised

- **Weeks 1–6:** QGIS foundations. You will install QGIS, explore the interface, practise symbology and layouts, work with administrative/statistical boundaries, and complete applied case studies (crime and health).
- **Week 7:** Bridge to Python. You'll set up Anaconda and learn how to replicate QGIS workflows in Jupyter notebooks.
- **Weeks 8–10:** Python automation. Notebooks focus on vector cleaning, raster/remote sensing, and transport network analysis.
- **Weeks 11–12:** Design studio and capstone. You will polish layouts, integrate accessibility best practices, and present a portfolio-ready project.

Use the left navigation to follow the weekly lecture notes and lab activities, or jump to reference materials (datasets, cheat sheets, setup guides). Each weekly lab page includes download links for notebooks and datasets.

## Who this course is for

- Curious beginners comfortable with basic command line usage.
- Learners with some exposure to Python plotting, but not mandatory.
- Anyone with a laptop capable of running QGIS and Jupyter notebooks (macOS, Windows, Linux).

## Learning outcomes

By the end of the course you will be able to:

1. Install and configure QGIS, navigate its interface, and manage spatial projects confidently.
2. Explain foundational GIS concepts, including vector vs. raster data, coordinate reference systems, and boundary hierarchies.
3. Perform cartography and geoprocessing tasks in QGIS to solve domain-specific problems.
4. Transition from GUI-based workflows to reproducible Python notebooks using a standardised environment.
5. Apply spatial statistics, remote sensing, and network analysis to crime, health, environmental, and transport datasets.
6. Design and present accessible maps using cartographic and graphic design principles.

## Getting started

**For Weeks 1-6 (QGIS):**

1. Visit **Getting Ready ▸ Install QGIS** to set up your software
2. Review **Getting Ready ▸ Understanding CRS** to understand coordinate systems (one of the most confusing GIS concepts!)
3. Work through **Downloading datasets** each week to get your data
4. Dive into **Week 1** to start your GIS journey!

**For Weeks 7-10 (Python):**

1. Read **Getting Ready ▸ Anaconda Setup** for detailed Python environment installation
2. Download notebooks directly from the weekly pages (Week 8, 9, 10)
3. See **Getting Ready ▸ Accessing Course Materials** for how to organize your files

**No Git knowledge required!** Just download what you need from the course website each week.

If you plan to publish your work, visit the **Reference ▸ Licensing** section to select appropriate content and code licenses.
