# Week 1 Lecture · Foundations of GIS

## This week
We introduce GIS as a way to connect location with descriptive data. Learners practise spatial thinking, explore QGIS for the first time, and understand how the course progresses from hands-on mapping to scripted analysis.

## By the end of the week you will
- Explain what GIS is and why geographic context matters.
- Identify the difference between vector and raster data models.
- Read basic metadata (CRS, extent, resolution) and note how it affects maps.
- Navigate the QGIS interface and produce a simple export from Natural Earth data.

## Key vocabulary
GIS · spatial data · attribute table · vector (point, line, polygon) · raster · metadata · coordinate reference system (CRS).

## What happens in class
- Contrast spatial vs tabular thinking with everyday examples (navigation apps, weather maps).
- Tour the QGIS interface and show where metadata lives.
- Demonstrate how to load and style Natural Earth layers, setting up the Week 1 lab.
- Outline the lightweight workflow: acquire → inspect → clean → analyse → communicate.

## Further Reading

**Essential:**
- [QGIS Training Manual](https://docs.qgis.org/3.34/en/docs/training_manual/) - Official step-by-step tutorials covering QGIS interface, basic operations, and data management
- [What is GIS? - Esri Overview](https://www.esri.com/en-us/what-is-gis/overview) - Comprehensive introduction to GIS concepts, applications, and core principles
- [Introduction to Coordinate Reference Systems](https://docs.qgis.org/3.34/en/docs/gentle_gis_introduction/coordinate_reference_systems.html) - QGIS Gentle Introduction explaining projections, datums, and why CRS matters
- [A Gentle Introduction to GIS - Vector Data](https://docs.qgis.org/3.34/en/docs/gentle_gis_introduction/vector_data.html) - Official QGIS guide covering points, lines, and polygons with clear examples

**Optional but recommended:**
- [The Geographic Information Science & Technology Body of Knowledge](https://gistbok.ucgis.org/) - Academic reference for GIS concepts, regularly updated by university consortium
- [Natural Earth Data Documentation](https://www.naturalearthdata.com/about/) - Learn about the free dataset used in labs and its metadata structure
- [Introduction to GIS - Spatial Thoughts](https://courses.spatialthoughts.com/introduction-to-qgis.html) - Free course covering spatial data fundamentals

**Videos:**
- [What is GIS? - National Geographic](https://www.youtube.com/watch?v=lGaFo_1hP5s) - 4-minute overview of spatial thinking and GIS applications
- [QGIS Quickstart Tutorial](https://www.youtube.com/watch?v=kCnNWyl9qSE) - 15-minute walkthrough of the QGIS interface and basic operations
