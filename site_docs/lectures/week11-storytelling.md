# Week 11 Lecture · Design & Storytelling Studio

## This week
We focus on how narrative structure, visual hierarchy, and accessibility principles transform technical maps into compelling spatial stories. Learners apply design critique frameworks, audit their work for inclusive communication, and refine maps for professional presentation.

## By the end of the week you will
- Apply narrative structure (hook, context, insight, call to action) to cartographic outputs and choose appropriate presentation formats.
- Conduct peer critiques using a structured rubric that evaluates clarity, hierarchy, accuracy, and accessibility.
- Audit maps for WCAG color contrast standards and color vision deficiency compatibility using testing tools.
- Write effective titles, annotations, and supporting narratives that guide interpretation without cluttering the visual.

## Key vocabulary
Visual hierarchy · narrative structure · accessibility · WCAG · color contrast · critique rubric · alternative text · design iteration · story map.

## What happens in class
- Analyze high-impact map stories and deconstruct design choices that support the narrative arc.
- Demonstrate accessibility testing workflows using Color Oracle and WebAIM contrast checker.
- Practice structured peer critique using the course rubric (clarity, hierarchy, accuracy, accessibility).
- Workshop map titles and annotations, transforming technical descriptions into audience-focused language.
- Review export best practices for different formats (print PDF, web PNG, archival standards).

## Prepare beforehand
- Gather 2-3 map layouts from previous weeks (Weeks 2, 5, 6, or recent work) and export as PDFs for critique.
- Install [Color Oracle](https://colororacle.org/) or bookmark [Coblis](https://www.color-blindness.com/coblis-color-blindness-simulator/) for accessibility testing.
- Review the [Design Critique Rubric](../reference/design-rubric.md) and [Accessibility Checklist](../reference/accessibility-checklist.md).
