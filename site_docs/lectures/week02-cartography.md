## Design as argument

Every design choice you make in a map is an argument about what matters.

Consider these choices:

- **Color ramp:** A sequential ramp (light to dark) implies "more is different." A diverging ramp (blue to white to red) implies "there's a meaningful middle." Same data, different framing.
- **Classification method:** Quantile makes all classes equal-sized—good for ranking. Natural breaks emphasizes clusters—good for finding groups. Equal interval emphasizes absolute differences—good for objective scales. Same numbers, different stories.
- **What's labeled:** If you label cities but not rivers, you're saying cities matter more for this map's purpose. If you label English names but not Indigenous names, you're making a choice about whose geography this represents.

This isn't manipulation—it's communication. But understanding that design shapes perception helps you:

1. Make intentional choices aligned with your message
2. Recognize when others' maps are framing data in particular ways
3. Communicate limitations honestly

### Classification as power

We'll practice different classification methods this week. As you experiment, notice: **the same numbers tell different stories depending on how you group them.**

A country with 15% renewable energy could appear:

- "Above average" (if using a classification where 10-20% is one class)
- "Below average" (if natural breaks cluster it with lower values)
- "In the middle" (if using equal intervals that split at 15%)

Who decides how to classify? You do. That's a responsibility, not just a technical choice.
