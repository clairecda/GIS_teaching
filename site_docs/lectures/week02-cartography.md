# Week 2 Lecture · Symbology, Labelling & Layouts

## This week
We focus on how design choices shape the story a map tells. Learners explore symbology, labelling, and layout to communicate data clearly and accessibly.

## By the end of the week you will
- Match data types to appropriate symbology and classification methods.
- Apply colour and typography principles to map labels and annotations.
- Build a balanced layout that contains essential map elements and proper attribution.

## Key vocabulary
Symbology · classification · sequential/diverging palette · label expression · layout hierarchy · accessibility.

## What happens in class
- Critique sample maps to identify effective design choices and pitfalls.
- Demonstrate categorical and graduated symbology using renewable energy data.
- Build expression-based labels for world cities with scale-dependent visibility.
- Assemble a map layout using the provided template and run through an accessibility checklist.

## Prepare beforehand
- Bring an inspiring map for the design show-and-tell.
- Read [Map Design Basics](../readings/week02-map-design-basics.md).
- Skim the [layout template](../reference/layout-template.md) and review the [Week 2 lab](../weeks/week02.md).

## Further Reading

**Essential:**
- [Cartography Guide - Axis Maps](https://www.axismaps.com/guide) - Comprehensive web-based guide to thematic mapping, visual hierarchy, and symbology choices
- [ColorBrewer 2.0](https://colorbrewer2.org/) - Interactive tool for selecting accessible color schemes for maps with guidance on sequential, diverging, and qualitative palettes
- [Map Design Principles - GIS Geography](https://gisgeography.com/map-elements-how-to-guide-map-making/) - Practical guide covering essential map elements and design
- [QGIS Map Design Tutorial](https://docs.qgis.org/3.34/en/docs/training_manual/map_composer/index.html) - Official documentation on print layouts and map production

**Optional but recommended:**
- [The Visual Display of Quantitative Information - Edward Tufte](https://www.edwardtufte.com/tufte/books_vdqi) - Classic reference on data visualization principles (book, excerpts available online)
- [Accessible Complex Images - W3C](https://www.w3.org/WAI/tutorials/images/complex/) - W3C guidelines for making maps and complex graphics accessible
- [Typography in Cartography](https://www.esri.com/arcgis-blog/products/arcgis-pro/mapping/please-label-responsibly/) - Esri blog on effective label placement and font selection
