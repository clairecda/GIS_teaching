## How to Use the Slides

- **Navigate**: Use arrow keys (← →), spacebar, or click the navigation buttons
- **Jump**: Press `Home` for first slide, `End` for last slide
- **Mobile**: Swipe left/right to navigate
- **Print**: Use browser print (Ctrl/Cmd+P) for PDF export

!!! tip "Keyboard Shortcuts"
    | Key | Action |
    |-----|--------|
    | → or Space | Next slide |
    | ← | Previous slide |
    | Home | First slide |
    | End | Last slide |
