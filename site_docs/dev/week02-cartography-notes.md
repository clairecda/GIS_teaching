# Week 2 Lecture · Cartographic Conventions & Colour

## Learning goals

1. Understand the essential elements every map should include (title, legend, scale, north arrow when needed, data credits).
2. Apply cartographic conventions to colour, typography, and symbol hierarchy.
3. Recognise colour connotations and accessibility considerations when styling thematic maps.

## Lecture outline

1. **Purpose-driven mapping**  
   - Audience and message first.  
   - Relationship between map type (choropleth, proportional symbol, dot density) and data structure.
2. **Map essentials checklist**  
   - Title/subtitle, legend, scale bar, north arrow (conditional), data/method credits, source links.  
   - Demonstrate how each element supports trust and interpretation.
3. **Colour theory & accessibility**  
   - Sequential vs diverging vs qualitative palettes.  
   - Introduce the [Esri colour connotations article](https://www.esri.com/arcgis-blog/products/arcgis-pro/mapping/color-connotations-and-associations).  
   - Discuss cultural interpretations (e.g., red ≠ universal danger), colour-blind safe palettes, and contrast ratios.
4. **Typography & layout**  
   - Font pairing, hierarchy, alignment to grids.  
   - White space management borrowed from magazine/layout design.  
   - Link to the [Layout template guide](../reference/layout-template.md).
5. **Case studies**  
   - Show good/bad map examples (e.g., misused colours, cluttered legends).  
   - Invite learners to critique using a rubric.

## Talking points

- Connotation vs perception: how red/green/blue are interpreted differently across cultures.
- Importance of data classification choices (equal interval, quantile, natural breaks) and how they affect perception.
- Use of annotation and callouts drawn from graphic design (magazine spreads) to lead the reader’s eye.
- Why every map should have explicit data and methodology attribution.

## Classroom activities

- Bring in magazine spreads or infographic examples and identify layout parallels.  
- Colour audit exercise: evaluate palette choices with colour-blind simulators.  
- Legend critique: swap legends and see if classmates can interpret the map without explanation.
