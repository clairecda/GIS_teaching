# Introduction to GIS

A 12-week, project-based course in geographic information systems. Students progress from QGIS fundamentals through Python-based spatial analysis to a capstone project.

**[View the course website](https://clairecda.github.io/GIS_teaching/)**

## What you'll learn

| Weeks | Focus | Skills |
|-------|-------|--------|
| 1-6 | QGIS Fundamentals | Loading data, symbology, layouts, spatial joins, terrain analysis |
| 7-10 | Python for GIS | GeoPandas, rasterio, remote sensing, network analysis |
| 11-12 | Capstone | Map design, storytelling, professional portfolios |

## Get started

1. Visit the **[course website](https://clairecda.github.io/GIS_teaching/)**
2. Follow the [setup guides](https://clairecda.github.io/GIS_teaching/onboarding/01-install-qgis/) to install QGIS
3. Work through weekly labs at your own pace
